MICROSOFT ONEDRIVE

PDF OneDrive archive

When the cloud status shows not connected, tap Connect OneDrive. The tablet remembers the Willow Park account so reconnecting should not require choosing the account again. Every submitted daily assessment then creates a readable PDF and files it automatically in the Willow Park Checks app folder in OneDrive.

Not connected Tap Connect OneDrive to enable automatic PDF backup.

Microsoft sign-in is handled securely by Microsoft. No Microsoft password or client secret is stored in this app. Daily PDFs are filed under Apps → Willow Park Checks → Risk Assessments → Academic Year → Term → Area. Outing PDFs are filed separately under Apps → Willow Park Checks → Outing Risk Assessments → Academic Year → Term.

DATA SAFETY

Backup & local storage

Assessments are stored in IndexedDB on this device and remain available without internet. Download a full JSON backup regularly for disaster recovery. Keep the public GitHub repository for the app code only — never upload completed nursery records there.
